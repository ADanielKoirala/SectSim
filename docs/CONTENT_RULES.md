# Content Rules

This file is intentionally thin right now. Cultivation realms, stage
counts, and detailed xianxia terminology are finalized when the
breakthrough system milestone begins (see ROADMAP.md) — not before,
per the "don't build ahead of the current milestone" rule in
ARCHITECTURE.md.

## Terminology used so far (from planning discussion, not final)

- Cultivation realms mentioned as examples during planning: Qi
  Gathering, Foundation Establishment, Golden Core. Qi Gathering has
  been discussed as having 9 stages. None of this is committed content
  yet — it becomes real when the breakthrough milestone defines it.
- General xianxia vocabulary to write in when relevant: qi, dao,
  meridians, dantian, cultivation base, tribulation, spiritual root,
  aptitude.

## Narrative voice (for the dev-time content pipeline)

- Third person, past tense, in the voice of a sect historian writing
  after the fact — not a live scene.
- English prose using xianxia genre conventions and terminology, in the
  register of translated xianxia web novels. Not literal Chinese-
  language output.
- Restrained rather than melodramatic.
- Normal events: 50-120 words. Historically important events: 150-250
  words.
- Templates use placeholder slots (`{disciple}`, `{pronoun_subj}`,
  `{pronoun_obj}`, `{pronoun_poss}`, `{mentor_or_ally}`, `{realm}`,
  etc.) rather than real names, so they can be authored once and reused.

This section will grow as each content-bearing system (cultivation
realms, spiritual roots, buildings, techniques, events) is implemented.
